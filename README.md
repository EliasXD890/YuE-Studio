<h2>🎯 How to Use YuE-Studio</h2>

<h3>First Launch</h3>
<p>When you open YuE-Studio for the first time, you'll see a welcome screen with a few options: create a new project, open an existing file, or explore built-in tutorials. Choose "New Project" to get started.</p>

<h3>Creating Music</h3>
<p>Select the "Generate" tab from the main menu. Type a description of the music you want—like "upbeat electronic dance track" or "calm acoustic guitar ballad"—and click the generate button. YuE-Studio will create a full track for you to listen to.</p>

<h3>Editing Audio</h3>
<p>Import any audio file by dragging it into the main workspace. You'll see a visual waveform of your sound. Use the tools in the toolbar to cut, copy, paste, or apply effects. Everything is reversible, so don't be afraid to experiment.</p>

<h3>Mastering</h3>
<p>When you're happy with your track, click "Master" in the side panel. Choose a preset style or adjust the sliders manually. Preview the result in real-time before you export.</p>

<h3>Exporting</h3>
<p>Click "Export" from the file menu. Choose your format: WAV, FLAC, or MP3. Select your quality settings and destination folder, then click "Save". Your music is ready to share!</p>
